ACESSIBILIDADE

Aprender deve ser
para todos.

O Educaí foi pensado para tornar o aprendizado mais acessível e facilitar os estudos de diferentes formas.

01

Recursos de acessibilidade

Conheça as ferramentas desenvolvidas para ajudar o estudante durante seus estudos.

01

Modo escuro

O modo escuro altera as cores da página, deixando o fundo mais escuro e o texto mais claro. Essa opção pode deixar a visualização mais confortável para algumas pessoas.

Como funciona?

O recurso foi desenvolvido utilizando JavaScript para adicionar ou remover uma classe no elemento principal da página.

02

Leitura em voz alta

O estudante pode escolher a opção "Quero ouvir" para transformar o conteúdo estudado em uma forma que possa ser acompanhada por áudio.

Como funciona?

O sistema utiliza o conteúdo enviado pelo estudante e trabalha esse texto para que ele possa ser utilizado pelo recurso de voz.

03

Tradução para Libras

O Educaí possui uma opção para traduzir o conteúdo enviado pelo estudante para Libras, buscando tornar o material mais acessível para pessoas surdas.

Como funciona?

O texto enviado é armazenado temporariamente e encaminhado para uma página específica de Libras, onde o conteúdo pode ser apresentado por meio do recurso de tradução.

04

Explicação simples

O estudante pode transformar um conteúdo em uma versão mais simples de compreender, facilitando a interpretação das informações.

Como funciona?

O sistema recebe o conteúdo enviado e organiza o texto para apresentar uma versão mais direta e fácil de acompanhar.

05

Resumo

O recurso de resumo apresenta uma síntese do conteúdo enviado, ajudando o estudante a encontrar as principais informações.

Como funciona?

O JavaScript recebe o texto e seleciona uma parte inicial do conteúdo para formar uma versão resumida.

06

Mapa mental

O mapa mental organiza as principais ideias do conteúdo em tópicos, ajudando na visualização e na organização das informações.

Como funciona?

O sistema apresenta uma estrutura com tema principal, conceitos importantes, informações, exemplos e conclusões.

07

Exercícios

O estudante pode gerar sugestões de exercícios relacionados ao conteúdo que está estudando.

Como funciona?

O sistema apresenta questões para ajudar o estudante a revisar e praticar o conteúdo.

02

Como os recursos foram desenvolvidos?

Os recursos de acessibilidade foram desenvolvidos utilizando tecnologias da web.

HTML

Utilizado para criar a estrutura das páginas, botões, campos de texto e conteúdos.

CSS

Responsável pela aparência do site, organização dos elementos, cores, tamanhos e adaptação para diferentes telas.

JavaScript

Utilizado para criar as interações e fazer os recursos funcionarem, como o modo escuro, pesquisa e transformação dos conteúdos.

NOSSO OBJETIVO

Tornar o estudo
mais acessível.

A acessibilidade no Educaí busca oferecer diferentes maneiras de acessar e compreender um mesmo conteúdo. Dessa forma, cada estudante pode utilizar os recursos que melhor atendem às suas necessidades durante o aprendizado.
